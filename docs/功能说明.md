# 功能说明

面向多商户电商企业的进销存管理系统，对接淘宝、拼多多、抖音、京东、快手、微信视频号、小红书 7 个国内电商平台的开放接口，覆盖商品、订单、库存、采购、发货全链路，并内置 AI 智能经营分析（详见 [AI 智能体说明](AI智能体说明.md)）。

## 商品管理

- SPU/SKU 双层数据模型，类目与类目属性体系，品牌管理
- 平台店铺商品与内部 SKU 映射归集，订单/库存/统计统一按内部 SKU 口径
- AI 商品文案优化：标题、卖点、描述、关键词草稿与站点规则检查
- 商品列表、批量管理、商品分类、供应商与 SKU 供货关系

## 订单管理

- 多平台订单与售后定时增量拉取，幂等去重入库，拉取日志可查
- 订单审核、状态流转，支持一单多明细、部分发货等场景
- 退款/售后台账，退款与原单匹配核对
- 打单发货：手工发货、打印、电子面单账户、供应商代发、云仓发货
- 订单转入后经 RabbitMQ 异步通知下游（手动 ACK、消费端幂等、死信队列兜底）

## 库存管理

- 多仓库、多库位管理，良品库存与订单锁定量分离
- 出入库单据流：采购入库、销售出库、调拨、盘点、领用
- 订单占用库存的锁定—释放—核销机制防止超卖
- 出库登记批次成本快照，支撑财务按结算口径核算利润
- AI 库存总览、补货估算与人机审核闭环

## 采购管理

- 采购单创建、审核、入库任务管理，未入库量按采购明细与实入台账核对
- 供应商档案、供应商报价、代发发货人管理

## 财务

- 已审核结算单利润核算：销售额 − 批次成本 − 运费 − 已审核费用单，单币种（人民币）
- 财务流水、费用单登记，平台账单导入
- AI 财务资料：订单级负利润穿透、多店对比

## 权限与系统管理

- RBAC 接口权限：用户、角色、菜单、字典管理
- 业务主体三级数据范围：总部 / 商户 / 店铺，账号经 `erp_business_user_binding` 绑定主体，服务端在 SQL 层拼接范围过滤，防止横向越权（详见 [业务账号权限与数据范围](业务账号权限与数据范围.md)）
- 系统消息与外部通知：飞书、钉钉、企业微信 Webhook 推送（详见 [消息与外部通知设计](消息与外部通知设计.md)）

## AI 智能体

LangGraph 工作流 + Java 权限门禁的双栈实现：自然语言经营分析（多主题并行）、SKU 表现排行、订单级亏损穿透、多店对比、明细导出、库存补货人工审核闭环。详见 [AI 智能体说明](AI智能体说明.md)。

## 技术栈

| 层 | 技术 |
